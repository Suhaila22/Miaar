# مِعيار — النسخة المستقلة (Standalone)

نسخة قابلة للتشغيل والاستضافة بشكل دائم خارج محادثات Claude.ai، بمفتاح Anthropic API خاص بكِ.

## الفرق عن نسخة الـ Artifact

| الميزة | نسخة Artifact (داخل المحادثة) | هذه النسخة المستقلة |
|---|---|---|
| التقييم بالذكاء الاصطناعي | عبر بيئة Claude.ai تلقائياً | عبر خادم بسيط يستخدم **مفتاح API الخاص بكِ** |
| حفظ البيانات | `window.storage` الخاص بالمحادثة | `localStorage` في متصفحكِ (يبقى على نفس الجهاز والمتصفح) |
| مكان التشغيل | داخل الرد في المحادثة فقط | أي مكان: جهازكِ، خادم داخلي، أو استضافة سحابية |

⚠️ **ملاحظة مهمة عن الحفظ:** `localStorage` مرتبط بالمتصفح والجهاز نفسه. إن فتحتِ التطبيق من جهاز آخر أو متصفح آخر، لن تري الترشيحات المحفوظة سابقاً. هذا مناسب للاستخدام الفردي. إن احتجتِ لاحقاً أن يشارك عدة أشخاص نفس لوحة الترشيحات (تخزين مركزي)، أخبريني وسأضيف قاعدة بيانات بسيطة (SQLite) بدل `localStorage`.

## التشغيل محلياً (على جهازكِ)

يتطلب [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
cd quality-judge-standalone
npm install
cp .env.example .env
```

افتحي ملف `.env` وضعي مفتاح Anthropic API الخاص بكِ (تحصلين عليه من [console.anthropic.com](https://console.anthropic.com/settings/keys)):

```
ANTHROPIC_API_KEY=sk-ant-...
```

ثم شغّلي الخادم:

```bash
npm start
```

وافتحي المتصفح على: **http://localhost:3000**

## الاستضافة الدائمة (اختياري)

لتشغيل التطبيق بشكل دائم يصل إليه فريقكِ عبر رابط ثابت، أي منصة تدعم تطبيقات Node.js تعمل مباشرة (Render، Railway، Fly.io، أو خادم داخلي لديكِ). الخطوات العامة تتشابه في أغلبها:

1. ارفعي هذا المجلد إلى مستودع Git (GitHub مثلاً) — تأكدي أن `.env` **غير** مرفوع (موجود في `.gitignore` مسبقاً).
2. أنشئي مشروعاً جديداً في المنصة المختارة واربطيه بالمستودع.
3. أضيفي متغير البيئة `ANTHROPIC_API_KEY` من إعدادات المشروع في المنصة (وليس داخل الكود).
4. أمر التشغيل: `npm start` — أمر البناء: `npm install`.

## أمان مفتاح API

المفتاح موجود فقط على الخادم (`server.js` يقرأه من `.env`) ولا يصل إلى المتصفح إطلاقاً — كل طلبات التقييم تمر عبر `/api/evaluate` على خادمكِ، الذي يضيف المفتاح قبل مناداة Anthropic. هذا يحمي المفتاح من الظهور في كود الصفحة كما كان سيحدث لو استُدعيت واجهة Anthropic مباشرة من المتصفح.

**لا تُشاركي ملف `.env` أو تضعيه في مستودع عام.**

## تعديل النموذج المستخدم

القيمة الافتراضية `claude-sonnet-4-6` مناسبة لمعظم الحالات. لتغييرها، أضيفي في `.env`:

```
ANTHROPIC_MODEL=claude-opus-4-...
```
